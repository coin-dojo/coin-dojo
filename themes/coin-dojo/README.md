# Coin Dojo — ES-DE theme

An original theme for the **ES-DE (EmulationStation Desktop Edition) 3.5.0**
frontend, built for a 4:3 six-button arcade cabinet
(1440×1080, pillarboxed). It uses the **modern v3 theme engine** — not the
legacy EmulationStation format.

Violet-black world (built to sit over a violet-blue backdrop): gold lead, warm red secondary, cream text; a crimson
scheme is selectable. A gold→teal chrome badge per system and a translucent control-deck
footer. The default backdrop is a dojo at night: moonlit shoji screens, a round moon window, a paper lantern and a
polished plank floor (`backdrops/default.png`, generated by `skills/badges/gen_backdrop.py`). Drop your own art
over it in `_inc/art/backdrops/` (see that folder's README).

Want your own theme? Start with `themes/README.md`: copy this folder, rename it, change the colours and the backdrop.

## Ships NO copyrighted artwork

This theme contains **only original art and OFL fonts**. There are no game
characters, logos, marquees, box art or other third-party copyrighted/
trademarked assets. Per-game media (cover, screenshot, marquee, video, …) is
**not shipped** — ES-DE pulls it from *your own* scraped media at runtime.

- Original art (backgrounds, the dojo backdrop, wordmark, panels, badges, textures): **CC BY-SA 4.0**

## Install / select in ES-DE

1. Copy this `coin-dojo/` folder into your ES-DE themes directory:
   - `~/ES-DE/themes/coin-dojo/`  (per-user), or
   - `<INSTALL>/themes/coin-dojo/` (system-wide).
2. Start ES-DE → **Main menu → UI settings → Theme** → choose **Coin Dojo**.
3. Tune under the same menu:
   - **Theme variant** — *Game media with videos*, *…without videos*, or it
     auto-falls back to *No game media* when a game has none scraped.
   - **Theme color scheme** — *Indigo* (default) or *Crimson*.
   - **Theme aspect ratio** — *4:3* (cabinet) or *16:9* (dev monitor).
   - **Theme font size** — *Medium* or *Large*.

## Layout

- **System view** — a horizontal carousel of system/collection badges over
  the backdrop, a category chip and game counter, a clock, a REV build stamp
  and the control-deck footer.
- **Gamelist view** — game list in a framed panel on the left; large
  cover / screenshot / video on the right (from scraped media), with
  description, rating (ki-spark stars), genre / players / maker / year, and
  status **badges** (favorites are off on the cabinet: no favorite badge, no
  favorites count in the header). Custom and auto collections render with the
  same look via the collection-header elements.

## Files

```
coin-dojo/
├── capabilities.xml        # theme name, aspect ratios, color schemes, variants, transitions
├── theme.xml               # includes, variables, and all view/element definitions (4:3-tuned)
├── colors.xml              # colorScheme "indigo" (default) + "crimson"
├── aspect-ratio-4-3.xml    # PRIMARY target + font-size (medium/large) tuning
├── aspect-ratio-16-9.xml   # widescreen fallback (wider bg + layout nudges)
├── README.md
├── LICENSE                 # points to repo MIT / CC BY-SA 4.0 / OFL
└── _inc/
    ├── fonts/              # OFL: Archivo Black, Rajdhani (Med/Semi/Bold), Press Start 2P (+ OFL-*.txt)
    ├── art/                # original art: SVG sources + PNG renders (loaded by the
    │                       #   theme; lunasvg can't draw the gradient SVGs), backdrops/
    ├── systems/ chips/ icons/ help/ controls/   # generated badges, chips, pictograms, help icons, cards
    └── per-system/         # SETTINGS / QUIT overrides
```
