# Box art and game info (scraping)

The cabinet can fetch pictures and facts for your games by itself. This is called **scraping**. No typing on a
computer is needed.

## What scraping gives you

- **Box art** and screenshots in the game menu.
- **Videos** of the games. In a list of games, press **MP** to see a game's pictures and video.
- **Game info**: the year, the maker, the genre and how many players.
- **Ratings**, the stars each game gets.

MUST PLAY and the genre lists are built from this info, so scrape first.

## First: make a free account

For a few games, you don't need an account: scraping works without one. For a full library, make your own free
account. You get a bigger daily limit, and scraping is faster.

On your computer or phone, go to **screenscraper.fr** and make a free account. Write down your user name and
password.

## Then: scrape on the cabinet

You need internet on the cabinet: a network cable, or Wi-Fi from **SETTINGS**, **WI-FI**.

1. On the game menu, press **START**. The main menu opens.
2. Pick **SCRAPER**.
3. Set **SCRAPE FROM** to **SCREENSCRAPER**.
4. Open **ACCOUNT SETTINGS**.
5. Pick **SCREENSCRAPER USERNAME**. An on-screen keyboard opens.
6. Type your user name: the stick moves, **LK** types a letter.
7. To finish, pick the tick mark at the right end of the top row of letters.
8. Do the same for **SCREENSCRAPER PASSWORD**.
9. Make sure **USE THIS ACCOUNT FOR SCREENSCRAPER** is on.
10. Press **MK** to go back to the SCRAPER menu.
11. Open **SCRAPE THESE SYSTEMS** and pick the systems you want.
12. Pick **START** at the bottom of the SCRAPER menu.

## How long it takes

A few games take minutes. A big library takes hours. Keep the cabinet switched on and let it work.

When it is done, it tells you how many games it scraped, and how many it skipped.

If it stops halfway, start it again: steps 1, 2, 11 and 12 above. Your account stays saved. To skip the games it
already did, set **SCRAPE THESE GAMES** to **NO GAME IMAGE** before you pick **START**.

## When something goes wrong

The cabinet shows a message on the screen. It offers **OK**, or **RETRY**, **SKIP** and **CANCEL**.

- **SCREENSCRAPER: WRONG USERNAME OR PASSWORD.** Pick **OK**. Type both again in **ACCOUNT SETTINGS**
  (steps 4 to 8). Check them on screenscraper.fr first.
- **YOU HAVE EXCEEDED YOUR DAILY SCRAPE QUOTA.** A free account can fetch only so much each day. Pick **CANCEL**
  and start again tomorrow.
- **NETWORK ERROR** (and more words). The cabinet has no internet. Check the cable or Wi-Fi, then pick **RETRY**.
- **SCREENSCRAPER ERROR** (and more words). The site is busy or closed for a while. Pick **CANCEL** and try again
  later.
- **A game is skipped.** The site did not know it. Usually the file name was changed, or it is a fan-made
  version (a "hack"). Keep arcade zip files under the name they came with. A skipped game still plays.

## Afterwards: rebuild the game lists

Now fill MUST PLAY and the genre lists:

1. On the game menu, turn the stick until **SETTINGS** is in the middle, press **LK**.
2. Pick **GAME LISTS**.
3. Pick **REBUILD GAME LISTS**. It takes about a minute.
4. It asks **RELOAD ES-DE NOW?** (ES-DE is the game menu.) Move to **YES**, press **LK**. The game menu starts
   again with the new lists.

More about the lists: [LISTS.md](LISTS.md).

## Your ScreenScraper password

The cabinet keeps this password without protection. Use a password you don't use anywhere else.
