# Coin Dojo instruction booklet

The setup guide as a retro game-box booklet, 16 pages. Same steps as [Start here](../START.md).

To print it: download [coin-dojo-manual.html](coin-dojo-manual.html) (the Raw button, then save), open it in your browser and print with background graphics on, A5 or US Letter.
